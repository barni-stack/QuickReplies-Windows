# Быстрые ответы

Распакуйте архив целиком и запустите QuickReplies.vbs двойным щелчком. Требуются Windows PowerShell 5.1 и Windows Script Host. Можно создать ярлык на рабочем столе.

Ctrl+F открывает поиск. Enter в поиске копирует первый ответ. Стрелка вниз переводит в список. Двойной щелчок или кнопка «Копировать» копируют выбранный текст. Вставка в рабочем чате — Ctrl+V.

Шаблоны хранятся в %LOCALAPPDATA%\QuickReplies. Для переноса используйте кнопки сохранения и восстановления копии. В архив входят исходники программы.
